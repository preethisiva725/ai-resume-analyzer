\## Features



\### Resume Analysis



\- Upload PDF resumes

\- Upload DOCX resumes

\- Extract resume text automatically

\- Compare resumes against job descriptions



\### Skill Matching



\- Identify matching skills

\- Identify missing skills

\- Detect technical skills

\- Detect soft skills

\- Calculate overall match score

\- Calculate technical skill score

\- Calculate soft skill score



\### Skill Priority Classification



The application categorizes job requirements into:



\- Required skills

\- Preferred skills

\- General skills



Missing skills are also classified as:



\- High priority

\- Medium priority

\- Low priority



\### Resume Quality Analysis



The application evaluates:



\- Contact information

\- LinkedIn profile

\- GitHub profile

\- Education

\- Work experience

\- Projects

\- Skills section

\- Action verbs

\- Quantifiable achievements

\- Resume length

\- Weak or vague phrases



\### Resume Statistics



The application calculates:



\- Word count

\- Action verb count

\- Quantifiable achievement count



\### Analysis History



Users can:



\- View previous analyses

\- Open previous results

\- Delete individual analyses

\- Clear analysis history



\### Downloadable Report



Users can download a report containing the main results of their resume analysis.
